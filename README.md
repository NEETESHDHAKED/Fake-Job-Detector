# 🚨 Fake Job Detector

Detect Fake Job Postings using Machine Learning & NLP.

## 🚀 Features
- Check Job is Real or Fake
- Enter Job Title & Description
- ML Model Prediction - Real / Fake
- Accuracy Score
- Job Posting Analysis

## 🛠️ Tech Stack
- Python
- Flask
- Machine Learning - Scikit-learn
- NLP - TF-IDF
- HTML / CSS / JavaScript

## 📦 How to Run
```bash
pip install -r requirements.txt
python app.py
